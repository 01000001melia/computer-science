<h2>CS50x 2024 - Introduction to Computer Science</h2>

<p>Completed Harvard's CS50x 2024 course, covering 10 weeks of introductory computer science topics</p>

<hr>

<h3>Course Structure &amp; Covered Topics</h3>

<ul>
  <li><strong>Week 0: Scratch</strong> - Visual programming concepts and basic logic flow.</li>
  <li><strong>Week 1: C</strong> - Syntax, data types, conditionals, and loops.</li>
  <li><strong>Week 2: Arrays</strong> - Command-line arguments, strings, and basic cryptography concepts.</li>
  <li><strong>Week 3: Algorithms</strong> - Linear search, binary search, and basic sorting algorithms (Bubble, Selection, Merge).</li>
  <li><strong>Week 4: Memory</strong> - Pointers, memory allocation, and pointers manipulation.</li>
  <li><strong>Week 5: Data Structures</strong> - Linked lists, queues, stacks, trees, and hash tables.</li>
  <li><strong>Week 6: Python</strong> - Rewriting C programs in Python to compare syntax and abstraction.</li>
  <li><strong>Week 7: SQL</strong> - Relational databases, SQL queries, indexing, and data filtering.</li>
  <li><strong>Week 8: HTML, CSS, JavaScript</strong> - Basics of web development and frontend interaction.</li>
  <li><strong>Week 9: Flask</strong> - Building basic web apps using Python and HTML forms.</li>
  <li><strong>Week 10: Cybersecurity</strong> - Overview of basic security concepts, threats, and privacy.</li>
</ul>
